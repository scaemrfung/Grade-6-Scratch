Scratch accounts

  1. Create a teacher account at scratch.mit.edu/educators if you want class tools. A regular account also works.
  2. Students under 13 need a parent or guardian email. Have a plan for that on day one.
  3. Create a class studio: Profile → Studios → New Studio. Name it Grade 6 Scratch – year.
  4. Write the studio URL on the board. Students add their published projects there starting Lesson 1.

How to use this website in class

  • Projector: Teacher view, open the lesson, run the Teacher demo cards.
  • Student devices: Student view. They only see goals, steps, Done when, Watch out, and the challenge.
  • Students tap a step when it is finished. Checks stay on that browser.
  • Stamp complete on the lesson page when most of the class has saved.

Shortcuts to teach

  • Duplicate a sprite: right-click the sprite thumbnail → duplicate
  • Undo: Ctrl+Z / Cmd+Z inside the paint editor
  • Green flag starts; red stop sign stops
  • File → Save now after every working feature
  • See inside a shared project to remix it
