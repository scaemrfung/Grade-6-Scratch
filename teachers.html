Scratch accounts

  1. Request a Teacher Account at scratch.mit.edu/educators/register. Approval can take a day. Then My Classes → New Class. Students join with your class link and do not need their own email.
  2. If students self-join at Join Scratch instead, Scratch still asks for a parent or guardian email under age 13.
  3. Create the class studio yourself (avatar → Profile → Studios → New Studio, or from the class page). Name it Grade 6 Scratch – year. Student accounts from a class cannot start new studios.
  4. Write the studio URL on the board. Students add Shared projects there starting Lesson 1.

How to use this website in class

  • Projector: Teacher view, open the lesson, run the Teacher demo cards.
  • Student devices: Student view. They only see goals, steps, Done when, Watch out, and the challenge.
  • Students tap a step when it is finished. Checks stay on that browser.
  • Stamp complete on the lesson page when most of the class has saved.

Shortcuts to teach

  • Default cat is named Sprite1. Trash can on the thumbnail deletes it.
  • Choose a Sprite / Choose a Backdrop: buttons in the sprite pane under the Stage. Library categories sit at the top (Letters, Music, Animals).
  • Add Extension is the puzzle-piece button under the block categories. Needed for Video Sensing and for Music play drum / play note.
  • Duplicate a sprite: right-click the thumbnail → duplicate
  • Undo: Ctrl+Z / Cmd+Z inside the paint editor
  • Green flag starts; red stop sign stops. Block name: when green flag clicked.
  • File → Save now, or Save Now in the top bar. File → Save to your computer makes a .sb3 backup.
  • My Stuff is under the avatar in the top right, not under File.
  • Share is the orange button on the project page, not inside the editor.
