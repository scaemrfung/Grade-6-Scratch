# Grade 6 Tech · Scratch

Classroom website for a Grade 6 Technology unit on Scratch.

Live site: https://scaemrfung.github.io/Grade-6-Scratch/

Thirteen click-by-click lessons built from the official Scratch coding cards (Animate a Name through Virtual Pet), four hand-in projects, and a published showcase. Stampable lessons and checkable steps.

Visual style matches the Grade 6 Canva and Grade 5 iMovie sites, with a teal Scratch palette instead of cocoa or blue.
