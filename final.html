Culminating project

Published Scratch showcase

One polished project that shows what the student can now build. Share it with the class studio and submit the live link.

What to include

  • A clear title and Instructions so a classmate can play without asking you
  • At least two skills from different units (for example music + scoring, or story + glide)
  • Credits in Notes and Credits if you remixed anyone
  • A published project, not an unsaved draft
  • One or two sentences: What I’m most proud of…

Student steps — do these in order

  1. Pick your strongest project. Open Animate a Name, the story, a game, or the Virtual Pet. File → Save as a copy and rename Showcase – Your Name.
  2. Polish one thing. Add a start screen, a win message, a sound, or cleaner costumes. Do not start a brand-new idea today.
  3. Write Instructions. Click the Instructions box on the project page. Tell the player which keys or clicks to use.
  4. Write Notes and Credits. Name any remixed project and the card set you followed.
  5. Share. Click Share so the project is public to the Scratch community.
  6. Add it to the class studio. Open the studio link from the board → Add projects → pick yours.
  7. Hand in the link. Copy the project URL (it looks like scratch.mit.edu/projects/…) and paste it where your teacher asked.

Suggested titles

  • My Scratch Journey
  • I Built This
  • From First Block to Game

Share-day checklist

  1. Collect live Scratch links only — no screenshots.
  2. Open See inside on two random projects. Code should match what the student claims.
  3. Confirm Instructions tell a new player how to start.
  4. Project the class studio and let two students play a classmate’s work.
  5. Stamp Lesson 12 when the studio has most of the class.

Rubric / 8 — Working features 3, instructions 2, polish 2, published + studio 1.
